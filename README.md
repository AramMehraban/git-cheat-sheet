# Git Cheat Sheet for Data Analysts & Developers

This repository contains a practical Git Cheat Sheet for beginners, 
Data Analysts, Python Developers, and students.

## Topics Covered

- Git configuration
- Repository initialization
- Clone and remote repositories
- Add, commit, status
- Branch and merge
- Push and pull
- Git log and history
- Git stash
- .gitignore

## Why Git?

Git and GitHub are important skills for:
- Data Analytics projects
- Python projects
- SQL projects
- Power BI portfolios
- Software development
